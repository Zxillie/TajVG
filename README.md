Ventures Group

A modern business website developed and published using HTML, CSS, and GitHub Pages.

Ventures Group is a professional ventures and investment-focused web platform designed to showcase innovation, business strategy, and forward-thinking opportunities. The website was created to provide a clean digital presence with responsive design and streamlined navigation.
